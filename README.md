# Horse Racing Companion website

Static, dependency-free marketing and App Store compliance site.

Production URL: <https://bpollak.github.io/horse-racing-companion/>

Stable App Store Connect URLs:

- Marketing: `https://bpollak.github.io/horse-racing-companion/`
- Support: `https://bpollak.github.io/horse-racing-companion/support/`
- Privacy policy: `https://bpollak.github.io/horse-racing-companion/privacy/`
- Privacy choices: `https://bpollak.github.io/horse-racing-companion/privacy/#choices`
- Terms: `https://bpollak.github.io/horse-racing-companion/terms/`
- Accessibility: `https://bpollak.github.io/horse-racing-companion/accessibility/`

The site is published from the `gh-pages` branch. To preview locally, serve the
`website` directory with any static HTTP server.
